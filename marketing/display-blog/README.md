# Campanha única: disp_blog (somente blog)

## Escopo
- 1 campanha Google Display: `disp_blog`
- Destino: apenas `https://danosaparentes.com.br/blog` e `/blog/[slug]`
- Sem landing de planos, locadoras ou oficinas nesta campanha

## Ad groups
1. `blog_artigos` — anúncios para artigos específicos (contextual + placements)
2. `blog_retarget` — quem já visitou `/blog` (7–30 dias)

## Arquivos
- `disp_blog_ads.csv` — URLs, headlines, UTMs
- `index.html` — preview dos banners 300×250 / 728×90 / 320×50

## UTM padrão
`utm_source=google&utm_medium=display&utm_campaign=disp_blog&utm_content={tamanho}_{slug}`
