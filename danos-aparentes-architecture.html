Danos Aparentes Vistoria digital de avarias veiculares — visão geral de arquitetura (PWA, Next.js + Supabase + Vercel)

1. Contexto de negócio

Objetivo: eliminar papel, redigitação e disputas na vistoria de veículos, gerando um laudo digital verificável (hash + QR Code) em minutos, direto do celular do inspetor — mesmo offline.

Usuários

Vistoriadores autônomos

Peritos e oficinas que emitem laudos avulsos.

Usuários

Locadoras / frotas

Checklist de entrada e devolução, plano Corporativo com múltiplos inspetores.

Usuários

Concessionárias

Avaliação de seminovos na entrada para revenda.

Valor

Prova de integridade

Hash SHA-256 + QR Code tornam o laudo auditável e impossível de alterar sem detecção.

4. Arquitetura em camadas

Cliente (PWA) Next.js 16 + React 19 TypeScript Tailwind CSS Framer Motion Service Worker (offline)
Estado local IndexedDB (db.ts) Fila de sincronização Cache de fotos
Funções serverless (Vercel) api/create-checkout-session api/stripe-webhook api/team-invite / team-accept-invite / team-reports app/api/tts
Backend (Supabase) Postgres (vehicle_inspections, damages, companies, team_members, subscriptions) Storage (damage-photos, document-photos) Auth (email/senha) Row Level Security
Serviços externos Stripe (Pro + Corporativo) Google Cloud TTS / ElevenLabs API de consulta de placa ZXing (leitura de código de barras CNH, offline)

5. Funcionalidades principais

Core

Diagrama interativo do veículo

6 tipos de veículo, 4 vistas externas por SVG clicável.

Core

Interior do veículo

Observações + fotos com legenda, sem exigir diagrama próprio.

IA/Voz

Confirmação por voz

8 vozes pt-BR (Google TTS Neural2/Chirp3-HD), confirma a peça clicada.

Autofill

Placa e CNH automáticas

Consulta de placa + leitura offline do código de barras da CNH (nome, CPF, nº habilitação).

Integridade

Hash + QR Code

SHA-256 do laudo + página pública /verify para auditoria.

Corporativo

Gestão de equipe

Convite de inspetores, dashboard do gestor com laudos de toda a equipe (somente leitura).

Offline

Funciona sem internet

Vistoria completa offline, sincroniza sozinha quando a rede volta.

Assinatura

Planos Pro e Corporativo

Stripe: Pro fixo (R$49,90/mês) e Corporativo com preço por faixa de inspetores.
